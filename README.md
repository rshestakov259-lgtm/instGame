# Кадр

Практикум Романа по коротким Reels. Семь глав включают 42 миссии. В последних четырёх ученик собирает видеобанк, монтирует ролик, ведёт календарь публикаций и сравнивает три замера статистики.

## Как продолжить с другого устройства

В профиле есть вход через ChatGPT. После входа ответы, миссии, закладки и календарь синхронизируются с базой курса. Если ученик занимался без входа, кнопка «Добавить ответы с этого устройства» переносит гостевые результаты. При повторном входе на другом устройстве открывается сохранённый прогресс. Отметки просмотра внешней подборки Reels остаются локальными. Полную резервную копию прогресса можно выгрузить в JSON из рюкзака.

## Запуск и проверка

Для локальной разработки нужен Node.js 22.13 или новее. Внешние npm-зависимости отсутствуют.

- `npm run dev` запускает практикум на порту 5173 в гостевом режиме. Для локальных проверок базы используется SQLite.
- `npm test` проверяет задания, совместимость сохранений и серверную синхронизацию.
- `npm run build` собирает клиентские файлы и Worker для Sites. Рабочая база D1 использует привязку `DB` и миграции из `drizzle/`. Хостинг добавляет идентификатор вошедшего посетителя.
- `python -m http.server 8000 --directory dist` подходит для просмотра гостевой версии.

## Где редактировать

Первый модуль находится в `dist/app.js`, остальные главы и календарь в `dist/course.js`. Задания, тренажёры и связанные результаты глав 4–7 находятся в `dist/workshop.js`. Два учебных видео и их постеры лежат в `dist/assets/practice/`. Скриншоты первого модуля описаны в `dist/visual-guide.js`, подборка второго находится в `dist/references.html`.

Правила совместимости сохранений находятся в `dist/state.js`, синхронизация в браузере в `dist/cloud.js`, серверный обработчик в `server/progress.mjs`. Он использует версию записи, чтобы объединять параллельные изменения. Гостевые и личные копии хранятся в разных ключах браузера.

## Совместная работа

Создавай ветку от актуальной main и открывай pull request с описанием и результатами проверок. Сохраняй ID миссий, ключи ответов, авторскую подачу и обработанные изображения со скрытыми личными данными. После объединения разверни сборку из того же снимка main в существующий Sites-проект. Для публикации нужны клиент, Worker, конфигурация с DB и миграции.
