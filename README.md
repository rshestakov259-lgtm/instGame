# Кадр
Практикум Романа по коротким Reels. В курсе 7 глав и 42 миссии. Прогресс сохраняется в браузере ученика.
## Запуск
Из корня проекта запусти `python -m http.server 8000 --directory dist` и открой http://localhost:8000. Проверки запускаются командой `node tests/regression.cjs`.
## Где редактировать
Первый модуль находится в dist/app.js, остальные главы и календарь в dist/course.js, скриншоты и пояснения в dist/visual-guide.js. Подборка для второго модуля находится в dist/references.html. Общие стили лежат в dist/style.css. За совместимость сохранений отвечает dist/state.js.
## Совместная работа
Для каждой задачи создавай ветку от актуальной main. Договорись с коллегой о границах изменений. Открой pull request с описанием и результатами проверки. Публикацию в Sites выполняет владелец после объединения изменений. Сохраняй ID миссий, ключи ответов, авторскую подачу от первого лица и обработанные изображения со скрытыми личными данными.
